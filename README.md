<h1 align=center><code>fht-share-picker</code></h1>

A share-picker application written for [`fht-compositor`](https://github.com/nferhat/fht-compositor)
in order to select a window/output/workspace for XDG screencast support!

This is **not** meant to be used alone! Internals and how this program works may change at any
moment, be warned.
